# Orbit — standalone Steps copy

Open `index.html` in a modern browser. The font, styles, graphics and demonstration data are embedded, so the HTML works offline. Keep `Manrope-OFL.txt` with redistributed copies. The separate Android version is `dist/Orbit.apk`, installed on the connected Galaxy S25 Ultra on 9 September 2026 as `com.mani.orbit`. It has its own icon, app storage and goal settings; the original Health app and Signal preview are unchanged.

Swipe the orb left or right to move between Steps, Heart rate, Sleep and Intake. Tap or keyboard arrows also change metrics. The figures, summaries and charts follow the chosen metric. Today, 7D and 30D change the period; the date button explores 30 demonstration days ending Monday, 8 September 2025, matching the reference. Additional earlier sample records support complete previous-period comparisons. Charts support keyboard selection and the arrow buttons open reading tables. Options contains the daily step goal and rotation toggle; the system reduced-motion preference also stops rotation.

Goals are saved under a separate browser storage key. Earlier browser verification changed its goal from 10,000 to 9,000 and confirmed it survived reloading. A fresh browser or Android installation starts at 10,000. The Android copy uses its own storage. Data is synthetic; there is no sensor, account or network connection. The APK requests no permissions and serves only its bundled page inside Android WebView. Android Back closes an open dialog, returns a selected metric/period to today's Steps, then exits the app.

Verification: rendered desktop page inspected against the supplied reference; Today/7D/30D and keyboard switching, goal saving/reloading and pause toggle exercised in the browser. `node verification/check.cjs` passes all four metrics across 30 dates and three periods, coherent hourly/sleep/food totals, complete previous periods, reference averages, a single animation loop, and reduced-motion/hidden-page stops. On the physical Galaxy S25 Ultra, installation, launch, orb swiping/tapping and all four metric views were checked. Local and installed APK hashes matched. The original Health app's installed package path remained unchanged. A full accessibility, performance, date-picker and device-compatibility audit has not been performed.

Rebuild with `python android/build.py` using the local Java 17 and Android SDK paths shown there, or supply JAVA_HOME/ANDROID_HOME. No external dependencies are downloaded. Preserve `android/signing/orbit-local.p12` for compatible local updates; this is a local development signing identity. Generated builds live under `android/build/`, and the latest APK is copied to `dist/Orbit.apk`.
