| --- | --- |

| `focus-fullscreen-art-inspiration.jpg` | Full-screen album-art composition. Interpret it within Orbit; use only real supported media controls. |

| `rejected-focus-small-orbit.jpg` | Remove the small timer orbit; retain real music and improve expressive numbers. |
